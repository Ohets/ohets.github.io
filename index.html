How to get started

1. Open the game

Choose “Open Air Simulator” to continue to the game page. Follow the sign-in or registration prompts if they appear.

2. Choose an activity

Once inside, use the available game menus to choose an aircraft, a mission or a scenery option.

3. Learn the controls

Read the on-screen labels and start with gentle turns, climbs and descents. Use the available camera options to help orient yourself.

For the best experience, use a modern browser and keep the game tab open while playing. Follow any control hints shown in the game interface.

About Air Simulator

Ohets Air Simulator is an independent browser game project. It is intended for entertainment and is not a certified flight-training tool. Aircraft behaviour and controls may differ from real-world aviation.

This public information page is available without signing in. The simulator itself may ask you to sign in before using gameplay features. Use the button above to continue to the game.
